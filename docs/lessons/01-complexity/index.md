# Сложность и O-нотация: лекция

## Цели темы

- Понимать, как измеряют эффективность алгоритма.
- Уметь оценивать сложность простых алгоритмов.

## Зачем нужна оценка сложности

Время работы в секундах зависит от компьютера. Поэтому считают, **как растёт число операций при росте размера входа** `n`.

## O-нотация

| Запись | Название | Пример |
|---|---|---|
| O(1) | константная | доступ к элементу массива |
| O(log n) | логарифмическая | бинарный поиск |
| O(n) | линейная | поиск максимума |
| O(n log n) | линеарифмическая | сортировка слиянием |
| O(n²) | квадратичная | пузырьковая сортировка |

## Пример

```python
def find_max(a):
    best = a[0]
    for x in a:        # n итераций
        if x > best:
            best = x
    return best        # итого O(n)
```

::: tip Правило
Отбрасываем константы и младшие слагаемые: `3n² + 5n + 2` → `O(n²)`.
:::
