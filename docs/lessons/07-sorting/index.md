## Сравнение

| Алгоритм | Лучший | Средний | Худший | Память |
|---|---|---|---|---|
| Пузырьком | O(n) | O(n²) | O(n²) | O(1) |
| Слиянием | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Быстрая | O(n log n) | O(n log n) | O(n²) | O(log n) |

## Пузырьковая сортировка

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:
            break
    return a
```
